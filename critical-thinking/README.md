A critical thinking applies structured reasoning to ask questions, collect evidences etc.

A natural way to associate these pieces is in the form of a graph, and the model defines different types of entities and relationships

YAML formal can be used to specify entities and relations: sunny-data\finance\investing\critical-thinking\checklist.yaml

Different analyses can be in different YAML, and a config file can specify which ones to load. Else, from GUI, filter the relevant nodes
